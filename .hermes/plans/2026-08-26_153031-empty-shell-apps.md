# Empty Shell Apps Plan

State: Approved for implementation

Goal: Reduce Live Splash and Weather to authenticated shells whose only app-body control is a “Go to Home” button, while preserving the existing login/logout behavior and leaving `services/api` unchanged.

Assumptions:

- Keep the shared authenticated header/account menu so the existing logout flow remains available.
- Route “Go to Home” to `/` on the shared Factory origin and to a configurable Factory Home URL for standalone deployments, defaulting to the local Home app.
- Delete app-local UI components, stories, styles, fixtures, hooks, client helpers, and tests that exist only for the removed experiences; retain auth, health, routing, and API proxy infrastructure.

1. [delegate-task] To-do: Replace Live Splash’s product UI with the authenticated shell and Home button, remove obsolete app-local UI/story coverage, and preserve its auth and routing contracts. To-verify: Run the focused Live Splash shell, login, logout, routing, health, lint, and build checks.
2. [delegate-task] To-do: Replace Weather’s product UI with the same authenticated shell and Home button, removing obsolete weather UI/support code and coverage while preserving its auth and routing contracts. To-verify: Run the focused Weather shell, login, logout, routing, health, lint, and build checks.
3. [delegate-task] To-do: Review the combined change for dead imports, unintended backend changes, and consistent standalone/shared-origin Home navigation. To-verify: Run `pnpm check` and confirm `services/api` has no diff.
4. [self-task] To-do: Present the running app shells for human app review and the staged diff for human code review. To-verify: Confirm both apps show only the shared auth shell plus “Go to Home,” and record approval or required changes before any commit.
